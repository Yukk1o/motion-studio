# AE 工程采集与分 PR 还原

目标是让复杂工程在 Motion Studio 中保留可编辑的合成、图层、动画和效果，并用源工程画面验证结果。基线主分支为 `0ca9665`。本次只提供采集工具、证据格式和开发交接，不改变运行时能力声明。

## 两层采集及证据边界

`tools/ae_project_audit.py` 使用 Python 标准库，读取 RIFX/Egg! 工程的部分结构，可选用 ffprobe 查询素材规格。输出工程 SHA-256、保存的合成记录、效果定义及效果实例的 matchName/偏移、表达式特征候选、未解析区域，以及与当前效果目录的匹配候选。

```powershell
python -X utf8 tools/ae_project_audit.py X:/local-input/project X:/private-output/audit --ffprobe ffprobe
```

这不是 `.aep` 导入器。工程中的效果定义不等于图层实际使用的效果；保存的实例也不等于启用、被最终合成引用的实例。工具不解码私有参数布局、关键帧、源引用或字体，不执行表达式。输出路径必须位于用户输入目录之外。偏移只是原文件的证据位置，不能作为编辑 ID。

`tools/ae_export_project.jsx` 在能够打开工程的 AE 中收集详细结构。AE 提供 ExtendScript 运行入口；使用方式见 [Adobe 脚本说明](https://helpx.adobe.com/after-effects/desktop/automate-in-after-effects/automate-animation/scripts.html)。用户工程、JSON 导出、成片、帧图、字体和第三方插件数据应保存在本地忽略目录，不能作为 Git 测试素材提交。

自动采集时，先复制 AEP 到独立的本地输入目录，在空的工具专用 AE 实例运行包装脚本：

```javascript
#include "X:/motion-studio/tools/ae_export_project.jsx"
var report = motionStudioExportProject({
    project: "X:/private-input-copy/project.aep",
    output: "X:/private-output/ae-export",
    rootName: "Main"
});
app.exitCode = report.state === "collected" ? 0 : 1;
app.exitAfterLaunchAndEval = true;
```

启动命令为 `AfterFX.exe -m -r <包装脚本绝对路径>`。不向已有的用户 AE 实例发送自动命令；脚本拒绝替换已有工程。手动采集已打开工程时，可省略 `project`，此时采集器保持当前工程打开。配置给出 `rootId` 时优先使用 ID，否则 `rootName` 必须唯一；没有唯一根时导出全部结构，并给出 `root_not_unique`。

输出为 `ae-project-export.json`，包括：

- AE 版本、工程工作色彩和表达式引擎，安装的效果 matchName/版本清单。
- 所有合成的 ID、尺寸、像素长宽比、帧率、时长、源引用图和指定根的可达集合。
- 图层顺序、类型、片段时刻、拉伸、父级、源引用、2D/3D、混合、轨道遮罩、音频、折叠变换和运动模糊开关。
- 属性树的索引路径和 matchName、启用状态、单位、宿主可读的硬范围、关键帧秒数、插值、时间缓动、空间切线和 roving 标记。
- Shape 顶点/切线、遮罩羽化数据、TextDocument 字体/排版和源文本、表达式源码和启用状态。
- 素材路径、缺失标记、Alpha 解释、原生/解释帧率及其他可读解释设置。

AE 2021 没有持久 `Layer.id`，回退 ID 为“合成 ID:图层索引”，`idKind=composition_index`；这类 ID 仅在这份快照内有效。支持该属性的新版本输出 `idKind=ae_layer_id`。属性地址由合成 ID、图层索引和属性索引路径组成，同时保留 matchName，以区分同名实例和版本。

关键帧以秒导出，不提前转为整数帧；不能静默将 23.976 fps 转成 24 fps。图层源引用的可达集合包含禁用图层，仍需根据时间范围、solo、guide、遮罩和效果依赖筛选真正的渲染图。不能仅排除禁用图层，因为它可能被效果读取。

采集器读取 `valueAtTime(0, true)` 和 `keyValue()`，保持表达式前的值；不采样表达式结果，不渲染，不改参数，不重连素材，不保存工程。打开工程本身仍依赖 AE 的正常载入行为。采集器自身不执行工程内的表达式字符串。

`CUSTOM_VALUE` 和其他不能可靠序列化的插件宿主对象标为不可读并报告警告。第三方 Curves/Looks/Designer 等内部对象不能靠此 JSON 声称完整恢复。`state=collected` 只表示结构采集完成，`restorationReady` 始终为 false；缺失插件、字体、素材、不可读参数和画面误差需要单独解决。当前脚本不验证字体是否安装，也不自动生成参考帧。

## 开发拆分与验收门槛

| PR | 范围 | 合并前应有的证据 |
| --- | --- | --- |
| 1，工程采集基准 | 本工具、JSON 契约、能力核对表和前后端交接 | 合成与效果定义/实例分离；源文件哈希不变；不执行表达式；不可读区域有报告 |
| 2，大素材与资源 | 大视频流式导入、共享文件引用、可见范围/分辨率驱动纹理、代理预览、冻结导出 | 代表素材导入/重开/取消/打包正确；源路径与时间准确；实机内存与播放统计；正式输出保留所选规格 |
| 3，遮罩与混合 | 图层遮罩路径/模式/羽化，Alpha/亮度轨道遮罩，工程使用的混合模式 | 半透明边缘、动画遮罩、跨层依赖、调整图层、子合成、wgpu/GLES 与冻结输出对照 |
| 4，矢量动画 | 工程使用的 Trim Paths、Repeater、组变换、渐变；延续现有路径模型 | 起止/偏移动画、开放/闭合多路径、重复顺序与透明度；保存及撤销；图层缩放和摄影机对照 |
| 5，表达式宿主 | `effect()`、图层/属性引用、控制器、`propertyGroup()`、`noise()` 与依赖图 | 同名实例定位、跨时间采样、确定性、循环依赖和错误定位、预算；前后端同步及保存恢复 |
| 6，文字动画 | 逐字/词/行选择器，字符变换，`textIndex/textTotal` 上下文与字体/排版 | 依赖 PR 5；工程中的代表文字片段可编辑、拖时间轴一致、预览与输出一致 |
| 7，时间映射 | 工程实际使用的时间拉伸、时间重映射、反向/冻结、混合帧率与音频时钟 | 正序/倒序/随机寻帧；片段与嵌套映射；缓存键与音视频冻结输出；不丢失小数时刻 |
| 8，跨图层效果 | SDK 输入层引用、采样空间和依赖生命周期；先验证 Displacement Map | 层选择/删除/复制、依赖循环、采样阶段、Alpha/边界、子合成和双端导出；必要时另拆音频 FFT 能力 |
| 9，工程用到的效果库 | 核对现有近似项；按可达实例补 Extract/Grid/Drop Shadow 等，再做特定复杂效果 | 每个效果有参数硬范围/单位/默认值记录、参考输入输出和误差报告；每个 PR 仅含少量有关联的效果 |

PR 9 是效果库系列，不能把全部第三方效果塞进一项变更。VHS/故障/抖色/像素排序、PrismLens/Flicker、音频频谱等按实际启用参数和片段分别交付。已有运动粒子和原生编辑器沿用独立 PR #32；继续完善 Particular 风格能力也应先核对目标实例的发射器、生命周期、精灵、力场、相机与混合设置。

不能从“有 106 个保存的合成”直接推出应把所有合成限制提高到 106；先确定目标根的可达节点数、展开实例数、深度、同时可见层和解码实例。现有 32 节点 / 8 级 / 64 展开实例、每节点 128 层和资源预算是明确限制，扩容需要缓存生命周期和压力证据。若数据确认必须提高限制，单独提交模型/存储/渲染/错误响应的一致更新。

## 前端交接

各功能由后端先交付版本化能力、项目字段、命令、采样语义、错误定位、撤销事务和 SDK 文档；通用界面交由前端实现。不能仅根据效果目录里出现一个名称就显示“已还原”。界面应区分已可编辑、近似实现、依赖缺失和不可读属性。

新增属性动画复用主时间轴和选中属性地址。原生插件专属页继续共享同一工程、播放头、参数轨道和历史，页面内关键帧与外部同步；不另存一套时间轴。字体、跨层引用或资源预算失效须定位到合成/图层/属性，预览可以显示问题状态，正式输出按照严格依赖检查处理。

## 整片验收

详细导出完成后，固定源工程 SHA、目标根、AE/插件版本、色彩、字体、素材解释与参考输出规格。选取文字、几何、转场、游戏视频、置换纹理、复杂光学和粒子等代表片段，先逐片段还原，再重建全部可编辑内容并连续播放和输出。

逐帧差异必须拆分未编码算法误差与成片编码误差；压缩成片适合核对结构、时间、构图和整体观感，不能代替 AE 未编码帧做 3/255 的算法验收。沿用已有未编码 RGB/Alpha MAE ≤3/255、MP4 全画面 <6 / 前景 <8 的约定，但明显的字形、运动时刻、遮罩错位和局部缺失不能被平均值掩盖。音频另验同步与采样范围。

Vivo Y300 Pro 等目标设备记录呈现帧率、p95 渲染/解码延迟、GPU/CPU 内存、长时间播放与发热后的表现。桌面离线读回吞吐、模拟器测试和手机持续预览帧率分别记录。

工具复验：

```powershell
python -X utf8 -m unittest discover -s tools -p test_ae_project_audit.py -v
node tools/test_ae_export_project.js
```

Python 用例使用自制 RIFX 小样本，JS 用例使用宿主 mock；二者不能代替在真实 AE 版本和已安装插件下执行采集。实际工程报告与真实 AE 验证结果放在本地 `artifacts/`，不上传参考工程或素材。
