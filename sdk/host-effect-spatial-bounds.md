# 效果空间边界与 Core Effects 1.4.0

效果可以在不修改图层位置、旋转、缩放、锚点或关键帧的情况下，移动整个输入平面或产生超出原图层的像素。输出范围属于效果渲染契约。预览与 PNG/MP4 导出使用同一输出矩形和原图层变换。

## 坐标和执行顺序

`output_bounds` 的 `x/y/width/height` 在未变换图层的像素坐标中求值，原始图层左上角是 `(0,0)`，Y 向下。它描述当前效果的完整输出区域，不只描述纹理尺寸。每个效果读取上一效果的输入矩形；随后颜色效果也必须保留该矩形的原点。

宿主按原图层的锚点和模型矩阵投影整个输出矩形，然后应用图层透明度并合成。外扩不会重新居中，也不会修改原图层的大小、锚点、父级或属性轨道。3D 图层的效果输出仍是该图层局部空间中的平面，随原来的模型和摄影机投影。场景生成器原有屏幕空间路径保持自身坐标契约。

WGSL 坐标字段如下；布局、参数块及 JNI 渲染计划仍沿用协议 3：

| 字段 | 含义 |
| --- | --- |
| `fx.region` | 当前 pass 输出矩形 `[x,y,width,height]` |
| `fx.input_region` | 当前 pass 读取的上一 pass/效果输入矩形 |
| `fx.source_region` | 当前效果的原始输入矩形，供效果透明度混合 |
| `fx.size` | `[原图层宽,原图层高,输出纹理宽,输出纹理高]`；不能代替上述逻辑矩形 |
| `fx.output_mode.w` | 当前预览缩放系数 |

预览降分辨率只影响纹理采样密度。位置、半径、输出边界表达式始终使用完整分辨率的图层像素。

## SDK 4 声明

SDK 1–3 效果包继续可用。使用新表达式运算时声明 `sdk_version: 4`，空间效果建议声明 `required_capabilities: ["rect_bounds", "spatial_bounds"]`。矩形与非零 `padding` 不能同时声明。

现有 `constant`、`parameter`、`input_size`、`input_origin`、`add`、`multiply`、`max`、`abs`、`ceil` 保留；SDK 4 新增：

| 运算 | JSON 字段 | 含义 |
| --- | --- | --- |
| `min` | `a,b` | 较小值 |
| `divide` | `a,b` | `a/b`，分母为零时报错 |
| `hypot` | `a,b` | 欧氏长度，避免先平方的中间值溢出 |
| `sqrt` | `value` | 平方根，负数时报错 |
| `sin` | `value` | 正弦，输入单位为**弧度** |
| `select` | `condition,a,b` | 条件大于零取 `a`，否则取 `b`；只计算选中的分支 |

表达式最大递归深度仍为 16；已求值节点必须有限且绝对值不超过 32768。输出宽高必须为正。合法参数组合仍可能超过设备尺寸或 64 MiB 临时纹理池预算，宿主明确返回错误，不缩小参数或悄悄裁切像素。

例如仅水平位移的效果，以下范围同时覆盖原平面和位移后的平面，可支持效果透明度混合：

```json
{
  "x": {"op":"add","a":{"op":"input_origin","component":0},"b":{"op":"min","a":{"op":"constant","value":0},"b":{"op":"parameter","id":"shift_x"}}},
  "y": {"op":"input_origin","component":1},
  "width": {"op":"add","a":{"op":"input_size","component":0},"b":{"op":"abs","value":{"op":"parameter","id":"shift_x"}}},
  "height": {"op":"input_size","component":1}
}
```

SDK 4 矩形效果在进行 `effect_opacity` 混合时，原始输入矩形以外的原像素视为透明。采样边缘模式不会把用于混合的原平面无限延伸。`edge_param` 为枚举时传递完整的 `0=透明、1=钳制、2=重复、3=镜像`；旧布尔边缘参数继续表示透明/钳制。

空间变换 shader 还必须判断反向映射后的坐标是否落在有限输入矩形中；仅声明外扩范围并启用重复采样，会把图层边缘填满整个输出。Shake 和 Transform Motion Blur 已按有限平面执行，边缘模式只影响其边界重采样。

## 本轮效果行为

| 效果 | 1.4.0 行为 |
| --- | --- |
| Shake / 抖动 | 位移、旋转与缩放作用于整个输入平面；按参数幅度的保守包络外扩，同一组静态参数的随机动画保持相同纹理尺寸 |
| Transform Motion Blur / 变换运动模糊 | 覆盖位移和 32 个运动采样的旋转/缩放包络；不会被原图层矩形截断 |
| Polar Coordinates / 极坐标 | 使用当前输入矩形；极坐标到直角坐标输出覆盖一周角度及输入对角半径，尾部可延伸到原图层下方，顶部原点保持不变；插值为零保持原图像 |

保守包络可能比实际可见像素大；当前不按随机噪声逐帧紧缩包络。资源仍由宿主池管理和复用。极坐标的中间插值继续采用反向坐标近似；这不是 AE 像素验收结果，兼容状态仍是 `approximate`。本轮不改变任何已有参数范围或默认值。

## 前端显式升级接口

现有工程继续保存原来的精确版本与 SHA-256；已发布 1.3.0 包保留原始字节。安装新版 App 不自动把旧工程中的效果改成 1.4.0。

先通过 `NativeBridge.plugin(session, {"op":"catalogue"})` 取得目标包的实际哈希，再调用：

```json
{
  "op": "upgrade",
  "object": 2,
  "instance": 1,
  "plugin": "com.motionstudio.effects.ae2021",
  "effect": "shake",
  "version": "1.4.0",
  "hash": "<catalogue 返回的 1.4.0 包 SHA-256>",
  "preserve_parameters": true
}
```

旧插件 ID 是已有工程依赖的稳定标识；用户界面和包文件名继续使用 Core Effects / `.msfx`。

成功返回现有 `{ "ok": true, "data": <完整 session snapshot> }`。升级保留实例 ID、效果链顺序、启用状态、种子、参数值、全部参数轨道/关键帧及场景编辑数据；一次升级对应一次撤销，可完整重做。前端用返回快照更新状态即可，不应另写图层位置或锚点来补偿效果位移。

`preserve_parameters` 为可选布尔值，默认 `false`，保留既有重新初始化升级行为。设为 `true` 时，旧包必须可解析，且插件 ID、效果 ID、参数定义和 renderer 契约完全相同；否则返回 `{ "ok": false, "error": "..." }`，工程及撤销状态不改变。跨效果或参数契约变化需要单独的迁移功能，不能静默丢弃部分轨道。本轮 Core 1.3.0→1.4.0 的 59 项参数契约均保持一致。

前端负责提供显式升级入口。本轮不添加通用效果面板 UI；旧实例要获得新的空间效果行为，需要调用上述接口或重新添加 1.4.0 效果。
