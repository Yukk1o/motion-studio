# Motion Studio 能力整合验证

分支 `codex/perlica-capabilities-integration-20261008`，主分支基准 `0ca9665285197c0d35c22ac3b5d4d1b57ef118e4`。整合 #32–#38 的运动粒子与 PNG 精灵、工程采集工具、大素材与工程包、按需图片加载、颜色／曲线、图层源蒙版及 Android runtime 拆分，提供一个可以一起测试的版本。未合并到主分支。

工程格式保持 8，包含颜色曲线和蒙版字段；渲染计划保持 v5／128 字节头。拆分后的 runtime 保留 56 个 Java JNI 入口与 `JNI_OnLoad`，ARM64 和 x86_64 实际导出表逐项一致。

## 整合修正

- 纯色图层的粒子只通过效果引用 PNG 时，也纳入预览及 GLES 冻结输出的素材需求集合；同一纹理跨帧复用。
- 图片缓存预算保留蒙版覆盖纹理的空间；蒙版输入与效果临时纹理共用原有预算检查。
- 粒子原生编辑页接入共用颜色参数行、色板／色环、收藏、常用色块和吸管。色盘覆盖参数区域，保留预览、时间轴与参数分组。
- 原生页使用后端局部颜色检查点：取消完整恢复该颜色轨道，保留其它页内修改；确认／取消等待已发送的预览值，整页仍一次撤销。控件切换期间以插件 token 校验会话归属。
- 粒子测试读取宿主实际计划版本；界面测试先滚动外层参数区域并确认按钮可见，覆盖横向色块行里的入口。

## 本地验证

- 首次整合后全工作区 Rust／GPU 测试：240 通过、0 失败、3 忽略。新增颜色检查点之后，5 项颜色曲线、3 项原生粒子编辑和 4 项编辑器协议测试共 12 项通过，包含两项新增测试。
- ARM64、x86_64 原生运行时、APK、测试 APK、14 项 JVM 检查及 Android lint 通过。
- API 35 模拟器，屏幕 `1080×2400 @420dpi`：最终 23 项 Android 检查通过。覆盖普通颜色／Alpha 曲线、收藏与吸管、粒子专属页、颜色局部取消与整页撤销、蒙版、场景效果、嵌套音视频和冻结输出。
- 新增综合工程 `1080×1920 @30fps` 同时使用源蒙版、颜色、Alpha 曲线及仅由粒子引用的 PNG。保存重开后创建冻结会话，编辑原会话不改变冻结数据；GLES 首帧上传一份精灵，第二帧复用。148 个检查点 RGB 平均绝对误差约 `0.0045/255`，Alpha 每点误差不超过 `3/255`。这是 wgpu／GLES 采样点检查，不代表全画面 AE 对照验收。
- AE 工程采集工具的 6 项合成数据检查和 JS 宿主模拟检查通过；未将模拟检查记为实际 AE 采集。

原始构建、测试、JNI 导出及采样报告保存在本机忽略的 `artifacts/perlica-integration-*`。APK、截图、参考目录和用户工程／素材不进入 Git。

本批是能力整合与验证；用户的完整“佩丽卡”可编辑工程还原尚未完成。轨道遮罩、更多混合与矢量／文字能力以及完整工程参数采集仍需后续交付。
