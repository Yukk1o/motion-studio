# 场景效果与插件专用编辑器

本次交付：SDK 2 `.msfx` 包、摄影机投影、实例化精灵渲染、确定性基础粒子、光源联动镜头光效，以及插件专用 HTML 编辑器和后端桥接。粒子页按发射、运动、外观、变换分组；镜头页提供光源绑定、元件列表和总控。插件页面已实现，App 的通用窗口容器、打开按钮和消息传输由 App 前端接入。

最新预装 `com.motionstudio.effects.scene@1.1.0`，包名 `scene-effects.msfx`；同时保留原始1.0.0包，旧工程继续使用精确版本与hash。修改插件页面也需要升级包版本；升级旧实例需显式操作，不自动替换：

| 一级分类 | 效果 | 能力 |
|---|---|---|
| 镜头光效 | Lens Flare / 镜头光效 | 可组合光晕、光环、鬼影、光条、星芒与色差；手动 3D 位置或图层/Null 世界枢轴跟随；距离衰减；源 Alpha 遮挡 |
| 粒子 | Starfield / 星空 | 3D 空间中的静态发光粒子 |
| 粒子 | Sparks / 火花 | 发射速度、随机方向、重力和寿命变化 |
| 粒子 | Dust / 尘埃 | 半透明漂浮精灵 |
| 粒子 | Snow / 飘雪 | 下降粒子 |
| 粒子 | Energy Particles / 能量粒子 | 发光、颜色和尺寸随寿命变化 |

算法与资源由 Motion Studio 独立提供，没有 Optical Flares、Particular、Element 3D 的二进制、代码或素材，也没有声称与这些产品一致。

生成器附在普通图层的效果链首位。图层变换成为粒子的发射器变换；生成结果在合成空间绘制，然后可以继续通过普通图像效果。保留每层 16 个效果的限制；粒子不是普通项目图层，不占用 128 个图层名额。

含场景状态的工程升级为格式 4；旧格式 1、2、3 继续读取。新增字段为 `EffectInstance.scene`，包括光源引用、遮挡开关和镜头元件列表。SDK 1 的已发布包及哈希不变，工程仍精确引用版本和 SHA-256。

后续宿主能力需要另行版本化：世界空间出生轨迹、动画出生参数、湍流与碰撞缓存、粒子/几何体深度交错、模型粒子、拖尾、景深、运动模糊、体积光和自定义模拟内核。插件 UI 可以自由布局；渲染能力由 SDK 明确声明。
