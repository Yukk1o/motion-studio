# 渲染和时间行为

## 粒子

时间来自图层局部帧 / fps。出生编号及 Seed 决定随机数；位置按出生时刻、初速度和恒定加速度解析计算，不积累逐帧状态。正序、倒序和随机寻帧采样相同。预热通过负出生编号实现；实际轨道数据、工程和 Seed 不会因采样改变。

位置先经发射器及父级世界变换，再用当前摄影机投影。精灵始终朝向摄影机，尺寸考虑透视和发射器缩放；支持观察摄影机。首版采用局部空间粒子：移动发射器也会移动已出生粒子，不模拟世界空间出生轨迹。

先用保守的包围球筛整个发射器，再筛每个投影矩形。判定范围包含完整精灵外观；部分进入画面的精灵保留。出生、寿命与随机编号不受可见性影响，摄影机移动后可以重新计算画面外粒子。没有按用户看到的区域重新生成随机粒子。

可见粒子在发射器内部按摄影机深度及出生编号排序，复用 CPU 排序缓存与 GPU 实例缓冲。GPU 一次实例化绘制一个生成器，只有可见实例上传；没有把每个粒子转换为普通 Layer，也没有逐粒子执行 JavaScript。

## 镜头光效

光源来自手动合成 XYZ 或引用图层/Null 的世界枢轴，投影到画面后构造镜头元件。Null 本身不参与图像绘制。源引用用于位置，不跟随其 visible 或片段启停；效果所属图层的片段和 enabled 控制光效是否绘制。摄影机后方和近远裁剪面外的光源不绘制。

遮挡通过从摄影机到光源的九条采样射线与可见图层平面相交计算，采样源图像 Alpha × 内容 Alpha × 图层透明度，并累乘透射率。支持 Solid、Image、文字光栅、透视、父级和半透明平面。图像 Alpha 缓存上传/导入时更新，不逐帧解码。遮挡平面必须位于光源前方；自身及场景生成器不作为遮挡物。

遮挡使用图层效果链之前的源 Alpha，不是场景几何深度缓冲，也不会采集模糊/扭曲后的 Alpha。单光源强度影响整组镜头元件，九点采样不是面积积分。后续可以加入显式遮挡层、合成深度、平滑遮挡和多光源绑定。

## 精度、合成和导出

生成器先在合成空间 RGBA16F 线性纹理累积，转换到既有 sRGB 纹理，然后执行后续图像效果；最终采用指定 alpha / additive 模式合成。半精度纹理避免大量半透明精灵在逐次 sRGB 8 位写回时放大双端误差。最终预览、PNG 和 MP4 沿用既有 8 位输出链，未提供 HDR 输出。

当前是按生成器图层整体排序后合成，粒子不会与其他图层/生成器逐粒子交错；没有碰撞、模型粒子、体积阴影、拖尾、景深或运动模糊。镜头元件是二维镜头成像现象，不是体积光束。

生成器必须是所属图层的第一个启用效果；之后可以连接普通调色、模糊、扭曲效果。启用的第二个生成器或前置图像效果会明确报错。问题效果预览保持它的输入并标记诊断；启用效果在隐藏图层上的依赖、顺序和容量错误也阻止正式导出。

上限：每效果 20,000 个存活粒子；每帧 65,536 个可见精灵；每层 16 个效果；临时纹理 64 MiB；Alpha CPU 缓存 32 MiB。RGBA16F 每像素 8 字节，已按实际字节计入临时预算。实例缓冲最多 3 MiB。超预算及不支持 RGBA16F 可渲染目标的设备明确报错，不减少出生数、缩小参数或裁切输出。

## JNI 帧计划版本 2

64 字节头和每 draw 128 字节保持；pass 从 32 字节扩为 40 字节。头索引 13/14/15 分别为实例区字节偏移、实例数量、实例大小 48。pass 新增索引 8/9：sprite_start、sprite_count。每实例是 rect（NDC 中心/完整尺寸）、color（线性预乘）和 style，各 4 个 f32。

纹理池新增槽 7（RGBA16F），mask 支持低 8 位；其他槽格式不变。program 元数据新增 sprite 和 additive。draw.words[23] 表示最终 additive 合成。原有 LUT、参数布局 624 字节及图像 shader 接口不变；GlEffects 和 MP4 适配器同步升级并拒绝不匹配版本。

冻结输出使用独立工程和精确插件资源引用；编辑器事务、参数修改和实时预览不改变已经运行的输出任务。
