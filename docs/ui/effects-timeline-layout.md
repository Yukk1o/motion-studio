# 效果属性与时间轴布局

原效果属性区覆盖图层时间轴，调参数时难以对照片段位置。现在效果编辑使用独立布局，预览、播放控制、当前图层时间轴和参数区同时显示。

## 操作

- 竖屏：预览、播放控制、当前图层时间轴、效果面板依次排列。
- 横屏：预览与效果面板左右排列，当前图层时间轴位于底部。
- 添加效果、编辑参数、颜色曲线和缓动曲线均保留时间轴。关闭效果后恢复完整图层时间轴。
- 点击参数名称选择当前参数；左右拖动刻度滑轮连续调整，点击数值精确输入。刻度随拖动移动，中心标记固定；点击滑轮远端不跳变到某个绝对值。大字体增加参数行高度，长列表可滚动。
- 当前参数共用上一关键帧、添加/删除关键帧、下一关键帧和缓动工具。参数区不再重复显示时间滑条、关键帧列表与播放按钮。
- 拖动时间轴更新当前帧、参数采样值和预览。长按关键帧可复制、移动或删除；已占用或超出合成范围的目标帧不能提交。
- 当前图层时间轴保留片段移动与裁剪；完整时间轴提供图层排序，避免单图层模式误改层级。
- 缓动曲线保留小圆点和对应连接线。较矮的横屏区域把预设移至图形右侧，保留曲线操作空间。
- 效果说明、兼容信息与版本切换放在更多菜单中；切换版本前明确告知参数及关键帧重置。

## 验证

33 项 Android 前端回归通过，覆盖效果链、刻度滑轮、无障碍数值调整、参数边界与撤销、时间轴寻帧、效果关键帧操作、曲线控制柄、独立坐标轴、片段编辑、普通属性面板和音视频导入与播放。六组布局验收通过，覆盖添加目录、参数和缓动编辑，并检查预览、时间轴、参数及播放区不重叠。33 个矢量图标生成检查一致。

验收期间，较早构建在 640 × 360 dp、字体 1.0 的布局检查中，测试进程曾在 Android ART 中因栈检查失败而退出。同一安装包重新运行该配置通过；现有堆栈不足以确定原因。首次结果、崩溃日志和重跑结果均保留在本地验收材料中。最终安装包六组配置全部通过，并直接检查滑轮中心标记的像素，避免只有触摸区域而未绘制刻度。

最终安装包的完整回归也有一次相同 ART 栈错误，同一安装包重新运行后 33 项全部通过。中断记录与堆栈均保留；尚未确认运行时崩溃的原因，需要其他 Android 运行环境进一步验证。

## 滑动更新与视频播放

滑轮使用连续数值和本地即时显示。一次手势中，相同对象、参数、轴和帧的待处理绝对赋值只保留最新值；不同编辑目标仍分别保留，位移等相对命令不参与替换。松手前提交最后的待处理值，然后保存为一次撤销；取消则丢弃待处理值并回滚手势。回归将 2500 次赋值合并为一次工程更新，两个效果参数与三个独立坐标轴的最终值和单次撤销均正确。这项检查验证更新队列行为，不作为设备帧率基准。

视频播放原来在每次刷新时替换尚未完成的解码目标。1920×1080、30 fps 测试素材复现播放时始终停在第 0 帧。现在完成并显示待解码帧后，再追赶当前播放时钟；暂停和重新播放使上一轮目标失效，音频时钟继续前进。连续播放测试直接读取预览 Surface 的像素，确认画面持续变化，并检查有声、无声和 1080p 素材，以及暂停后的寻帧。原生解码与接口未修改。
