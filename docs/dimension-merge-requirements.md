# XYZ 取消分离需求

当前接口提供 `separate_dimensions` 和单轴编辑，没有合并回整体向量属性的命令。分离操作可撤销，但这不能代替编辑多个独立轨道后随时取消分离。

## 范围与行为

- 图层 position、rotation、scale，以及摄影机 position、target。
- 取消分离后回到整体关键帧与整体曲线编辑，当前画面、动画轨道及未使用的 Z 数据必须保留。
- 静态属性直接合并 XYZ 静态值。关键帧时间和缓动定义完全一致的三轴，可无损合并为向量关键帧；保留曲线、自定义参数及多圈旋转值。
- 三轴时间或曲线不一致时，整体轨道的一套缓动不能表示任意三套曲线。默认必须返回“需要烘焙”，保持工程和历史不变，不得删掉某轴、套用某一轴曲线或悄悄烘焙。
- 显式逐帧烘焙可作为另一种合并方式：保证指定范围内每个整数帧的 XYZ 采样一致，并告知子帧插值可能变化。保留片段外原始动画的规则和范围必须由接口明确，不能只合并当前可见片段。

## 建议接口（待实现）

```json
{"op":"combine_dimensions","object":2,"property":"position","mode":"exact"}
```

另行约定 `mode:"bake"` 的范围、采样率、误差和超限保护。不能以属性名称相同推断三轴兼容，必须检查完整的 key/ease/curve 定义；无动画的轴也应纳入静态值求值。

状态需提供能力标志、允许的属性和合并方式。失败返回结构化原因，如 `requires_baking`、`locked`、`unsupported_property`；成功立即返回整体轨道状态及转换结果。一次合并属于一个原子历史操作，支持撤销、重做、保存与重新打开，按图层局部时间保留 offset，且不更改父级或 2D/3D 模式。

## 验收

覆盖静态三轴、相同时间和曲线、不同时刻、不同曲线、弹性曲线、多圈旋转、负局部帧、片段移动与裁剪、摄影机目标点、2D 隐藏 Z、锁定及异常回滚。无损合并验证整数帧和子帧求值；烘焙验证约定采样点并报告子帧误差。合并前后检查预览、PNG、MP4、撤销/重做和持久化一致性。

前端等真实能力标志和命令可用后接入“取消分离”。需要烘焙时先说明动画变化和关键帧数量，用户明确选择后再提交转换。
